# 📊 Sales Analysis & Performance Report

A practical sales performance report created in Microsoft Excel analyzing employee targets, achievements, and performance ratios.

---

### 🏢 Company & Project Overview
- **Organization:** Mastery PVT LTD Company
- **Location:** Dhaka, Bangladesh
- **Reporting Period:** June 2026 Sales Analysis

---

### 📌 Key Highlights & Structure
- **Employee Demographics:** Tracks Employee Name, ID, and Regional Location (e.g., Khulna, Dhaka, Barisal, Joshor).
- **Product Categories Analyzed:** Target vs. Achievement tracked across multiple hardware lines:
  - Monitor
  - Printer
  - SSD
  - CPU
  - Keyboard
  - Computer
- **Key Metrics Calculated:**
  - **Total Target:** Sum of targets across all hardware categories.
  - **Total Achievement:** Total sales generated per employee.
  - **Achievement Ratio (%):** Performance evaluation comparing actual achievement against assigned targets.

---

### 🛠️ Tools & Skills Demonstrated
- **Tool:** Microsoft Excel / CSV
- **Functions Used:** `SUM`, Percentage formulas, Ratio calculation, Tabular data modeling, and reporting layout design.
